# DungeonDuelists_Jam

A turn-based strategy game created for a game jam, featuring card-based combat, monster battles, and a deck-building system.

## Features
- Turn-based card and monster combat
- Deck customization and management
- Multiple game stages and enemies
- Sound effects and visual assets

## Setup
1. Clone the repository
2. Open the project in GameMaker Studio 2
3. Ensure all dependencies are included (GMLive runtime files in datafiles/GMLive)

## Folder Structure
- `datafiles/`: Contains fonts, sound effects, and GMLive runtime files
- `fonts/`: Custom font assets
- `sounds/`: Game sound effects

## Running the Game
1. Open `GameMaker Studio 2`
2. Load the project from the root directory
3. Run the game using the default room (Room1)

## Dependencies
- GameMaker Studio 2
- GMLive runtime (included in datafiles/GMLive)

## Game Structure Overview
The project contains:
- **Core Systems**: Card mechanics, monster AI, and turn management in `scripts/`
- **Visual Assets**: Sprites for cards, monsters, UI elements in `sprites/`
- **Audio**: Sound effects for actions and UI feedback in `sounds/`
- **Game Logic**: Room definitions and object behaviors in `rooms/objects/`

## Roadmap to Enhance Fun Factor
To make the game more engaging, consider these additions:

1. **Tutorial System**
   - Add a guided tutorial for new players
   - Include card mechanics, deck building, and basic combat strategies

2. **Deck Balance Pass**
   - Analyze card interactions to prevent meta exploits
   - Introduce card synergies and counter-strategies

3. **Multiplayer Mode**
   - Implement local multiplayer for card duels
   - Add turn-based sync and victory conditions

4. **Enemy AI Expansion**
   - Create smarter enemy behaviors with adaptive strategies
   - Add special abilities for boss enemies

5. **Progression System**
   - Introduce character levels and experience points
   - Add rewards for completing stages and defeating bosses

6. **Cosmetic Upgrades**
   - Allow card and monster customization (skins, animations)
   - Add collectible card back designs

7. **Leaderboard System**
   - Track high scores for stages and battles
   - Add competitive rankings for top players

8. **UI/UX Improvements**
   - Add animated transitions between turns
   - Implement drag-and-drop deck building
